Stroke data for the "Write it" page of the Chinese lesson games.

Each file (named by the character's code point, e.g. 4fe1.json) holds one character's strokes and stroke medians.
Source: Make Me a Hanzi (Shaunak Kishore), as packaged in hanzi-writer-data 2.0.1 (npm).
That data is derived from the fonts AR PL KaitiM GB and AR PL UKai by Arphic Technology Co., Ltd.
It is unchanged here, apart from being saved again with only the fields "strokes", "medians" and "radStrokes".
